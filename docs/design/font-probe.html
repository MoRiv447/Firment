选定之后要做的两件事(不是换个名字就完)

  • 字体文件要随应用打包。现在的 --ff-sans 里写着 Inter,但仓库里没有 woff2、index.html 也没有预加载 —— 所以它一直没生效,你看到的是兜底。 正式做法是把 woff2 放进 gui/src/assets/,用 @font-face(font-display: swap)引入,并且做子集化(只取拉丁 + 常用标点),否则一个 CJK 字体动辄几 MB。
  • 中文字体不能只靠 sans 兜底。我们的界面里中文占一半,而 Inter / Geist / Plex 都没有汉字 ✗ —— 所以栈里必须留一个中文回退(现在写的是 Noto Sans SC,同样没随应用打包)。 最省事的做法:西文用选定字体,中文交给系统(system-ui 在 Windows 上就是微软雅黑),不必打包中文字体 —— 代价是中文的字形随系统而异。
