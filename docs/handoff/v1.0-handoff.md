## 2. 硬性规矩（违反会踩真坑）

来源：仓库 `AGENTS.md`，**必须遵守**。

1. **cargo 严格串行**。绝不并发跑两个 cargo 命令（会 `Blocking waiting for file lock`）。fmt → clippy → test 依次等它退出。
2. **`gui/src-tauri` 是独立 cargo workspace**（自己的 `Cargo.toml` / `target/` / `Cargo.lock`）。根目录的 cargo 命令**覆盖不到它**，必须在它自己目录里跑。
3. **绝不删锁文件**（`.cargo-build-lock` / `.cargo-lock` / `.cargo-artifact-lock` / `~/.cargo/.package-cache`）。cargo 卡住时先 `tasklist` 找真持有者，卡太久就 kill 那个 PID。**不要 `cargo clean`**。
4. **`Blocking waiting for file lock` 能自己解开是正常的**，不要"修"它。
5. **os error 5（拒绝访问）是环境问题**（安全软件拦截），不是代码问题。报告一次并停下，不要循环重试。
6. **提交风格**：conventional commits（`feat:` / `fix:` / `refactor:` / `docs:` / `chore:`），scope 用 `(web)` / `(tui)` / `(cli)` / `(core)`。
7. **CHANGELOG 格式**：`## vX.Y.Z (YYYY-MM-DD) — 标题`，release workflow 按 `## <tag>` 逐字提取。
8. **引用的数字必须核实过**（历史上出现过"18 个单测"实际 17 个）。
9. **借用他人项目的思路要独立实现、独立措辞**，不要移植有署名要求的散文或代码。

## 6. 视觉规范（做 UI 时照这个，不要另造数值）

完整版在 `docs/design/tokens.md`。要点：

- **品牌绿 `#B4F779`（85° 酸绿）只用于 4 处**：logo、主 CTA、进度条、当前步。**绝不做状态反馈**，**绝不当文字色**（浅底 1.8:1，是荧光笔不是墨水）。
- **成功绿 `#16A34A` / `#86EFAC`（145° 正绿）是状态反馈**，与品牌绿**色相差 60°，肉眼可分**。语义：交通灯的绿代表通过，酸绿是品牌个性。
- **底色与文字全中性**。界面偏绿会让 diff 的红绿失真，而 Firment 界面大半是 diff。
- **斜切是唯一不可替代的签名**：有文字的元素用 `clip-path`（**绝不整体 `skewX`**，会让文字反向斜）；斜切量 12px / 缝 8px / 左 padding 比右多 5px 做光学居中。
- **圆角分级**：logo/图标 0 · 徽章 2 · 控件 4 · 卡片 8。**12px 会把斜切吃掉**。
- **按钮三级权重、同排必须等高 40px**，用颜色而非大小拉开主次。
- **动效**：`cubic-bezier(.2,.8,.2,1)`，进入 160 / 常态 200 / 退出 120ms。**TUI 上限 15fps**（Windows Console / SSH / tmux 高频重绘闪屏），且 `SSH_CONNECTION` / `TERM=dumb` / 非 TTY 时**完全禁用**。
- **三态语义**：未配置 → 整块隐藏；已配置无数据 → 中性提示；只有真出错 → 才报红。未知态用 `○`，**绝不用 `✗`**（未知 ≠ 失败）。

## 7. 踩过的坑（照做能省时间）

1. **PowerShell 的 `>` 重定向写 UTF-16LE + BOM**。它把 `web/src/lib/tools/specs.json` 写坏过，导致两个 Web 测试套件**加载失败**。重生成快照必须走 .NET：
   ```powershell
   $t = [System.IO.File]::ReadAllText("$PWD\.firment\live.json")
   [System.IO.File]::WriteAllText("$PWD\web\src\lib\tools\specs.json", $t, (New-Object System.Text.UTF8Encoding($false)))
   ```
2. **PowerShell 不支持 heredoc**（`<<'EOF'` 会报错）。多行文本写进 `.firment/xxx.txt` 再 `git commit -F`。
3. **`@import` 必须是 CSS 文件的第一条规则**。PostCSS 把 `@tailwind` 展开成一大块，`@import` 落到 1197 行时构建直接报 `must precede all rules`。
4. **`cargo fmt` 会重排文件**，之后 `edit` 工具会报 "file changed since it was read" —— 重新 `read` 再改。
5. **TUI 完成态卡片的行缓存**：`Item::Tool` 的渲染行按 `row_version` 缓存，**改完内容必须 `touch_rows()`**，否则一直显示旧内容（运行中的卡片因为 `is_row_dynamic` 侥幸不犯）。
6. **TUI 的 `KeyCode::Char(ch)` 匹配任意修饰键**：新增 Ctrl 快捷键**必须**插在它之前，否则会被当字符插进输入框。已占用 `Ctrl+P/A/E/C/V/Q/Shift+C`。
7. **`gui/src-tauri` 的 `FrontendEvent` 是独立镜像类型**，`AgentEvent` 加字段这里会**穷尽性编译错误**（独立 workspace，要单独 check）。
8. **`gui/tsconfig.json` 开了 `noUnusedLocals`/`noUnusedParameters`**：拆文件时任何残留 import 都会让 `npm run build` 失败。
9. **`web` 的 `ChatPage.tsx:98` 用 `filter((m) => m.role !== 'tool')` 把持久化的工具结果整个丢掉**，所以 Web 端的工具输出只有瞬时 SSE、刷新即失。要在 Web 显示 diff 历史，必须改这个 filter 或另建按 `toolCallId` 索引的状态。
10. **`firment-cli` 原先没有直接依赖 `serde`**（只有 `serde_json`）；用 `#[derive(Serialize)]` 需要加 `serde.workspace = true`。
11. **logo 生成脚本的取景数学**：标志比高宽 27%，只按高度缩放会把顶栏顶到右边缘；`slack` 为负时按 slack 比例做偏移会让字形**反向偏出画布**；校验"着墨边界"必须设 alpha 阈值（LANCZOS 的 1–2px 边缘会量出假的 0 边距）。这三条都已在脚本里固化成断言。
12. **`web/.bak-20260812/`** 是陈旧备份目录（已 gitignore，含另一份 755 行的 `ChatPage.tsx`）。grep 工具会跳过它，但人肉搜索容易踩。
